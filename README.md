# NatGeo Study Reader · 外刊学习助手

一个用于个人学习 National Geographic 文章的本地小网站。可以获取文章公开信息、整理正文、并一键导出为可打印的 DOCX。

## 功能

- 粘贴 National Geographic 文章链接，自动获取标题、摘要、作者、发布日期、封面图等元信息。
- 支持导入已有的 `.docx` 文件（比如你上传的模板），自动提取标题与正文。
- 正文按空行分段，自动添加 `[1] [2] …` 编号，方便精读与批注。
- 实时打印预览，支持直接打印。
- 一键「复制到 Word」：粘贴到 Microsoft Word 时保留格式。
- 一键「下载 DOCX」：生成排版好的 Word 文档。
- 浏览器本地保存文章列表，方便下次继续学习。

## 本地使用方式

1. 打开终端，进入项目文件夹：

   ```bash
   cd natgeo-reader
   ```

2. 安装依赖（首次使用）：

   ```bash
   pip install -r requirements.txt
   ```

3. 启动本地服务：

   ```bash
   python app.py
   ```

4. 在浏览器打开：

   ```
   http://127.0.0.1:5000
   ```

## 手机访问方式

### 方式一：同一 Wi-Fi 下直接用局域网 IP（最简单）

启动服务后，终端会显示本机局域网地址，例如：

```
Running on http://192.168.1.14:5000
```

只要手机和电脑连接同一个 Wi-Fi，在手机上打开这个地址即可访问。

### 方式二：临时公网链接（适合外出访问）

需要电脑保持开机并联网。在另一个终端运行：

```bash
npx localtunnel --port 5000
```

会生成一个类似 `https://xxx.loca.lt` 的公网链接，手机用浏览器打开即可。首次访问可能需要输入页面上显示的 IP 地址验证。

### 方式三：永久部署到 Render（推荐长期使用）

1. 把整个 `natgeo-reader` 文件夹上传到 GitHub 仓库。
2. 注册并登录 [Render](https://render.com/)。
3. 在 Render Dashboard 选择 **New + → Web Service**，连接你的 GitHub 仓库。
4. Render 会自动识别 `render.yaml`，完成部署后会给你一个永久域名，手机随时访问。

> 免费套餐会有休眠机制：一段时间没人访问后，首次打开需要等待约 30 秒唤醒。

## 关于实时更新与版权

National Geographic 目前不提供免费的公开全文 API，且直接抓取整篇文章内容可能违反其使用条款。因此本工具：

- 只从文章页面读取公开的标题、摘要、作者、日期等元信息；
- 正文需要你自己从合法渠道（订阅、杂志、官方网页复制等）粘贴到编辑区；
- 你可以导入自己已经保存的 `.docx` 文件继续编辑。

本工具仅供个人学习使用，请遵守 National Geographic 的版权与服务条款。
